Debug Console Output

Buka browser console (F12) dan jalankan:

// Di halaman paket perjalanan, jalankan ini di console:
let data = Alpine.$data(document.querySelector('[x-data*="packageManagement"]'));
console.log('HPP Form:', data.hppForm);
console.log('Selected Package:', data.selectedPackage);
console.log('Capacity:', data.selectedPackage?.capacity);
console.log('Total HPP:', data.calculateTotalHpp());
console.log('Flight Cost:', data.hppForm.flight_cost);
console.log('Hotel Cost:', data.hppForm.hotel_cost);

Checklist Troubleshooting

  1. ✅ Pastikan paket memiliki kapasitas yang diisi (bukan 0 atau NULL)
  2. ✅ Pastikan HPP data sudah disimpan di database (cek tabel hpp_calculations)
  3. ✅ Clear cache Laravel: php artisan view:clear && php artisan route:clear
  4. ✅ Hard refresh browser: Ctrl + Shift + R (Windows) atau Cmd + Shift + R (Mac)
  5. ✅ Cek browser console untuk error JavaScript
  6. ✅ Verifikasi data loading dengan console command di atas
