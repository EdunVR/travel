🗑️ Kontra Bon - Fitur Hapus

✅ SELESAI
📋 Ringkasan: Fitur hapus kontra bon telah berhasil ditambahkan pada halaman List Kontra Bon dengan permission check dan restore status piutang otomatis.

🎯 Fitur Utama

🔘 Tombol Hapus

Icon trash merah di kolom Aksi, hanya muncul untuk user dengan permission

🔄 Restore Piutang

Status piutang otomatis dikembalikan ke "belum lunas" saat kontra bon dihapus

🔒 Permission Check

Hanya user dengan permission sales.kontrabon.delete yang bisa hapus

⚡ Transaction Safe

Menggunakan DB transaction untuk memastikan data consistency

📊 Tampilan Tabel

Tanggal No. Kontra Bon Customer Total Jatuh Tempo Status Aksi
09/02/2026 KB202602001 PT. Contoh Rp 5.000.000 16/02/2026 Pending
08/02/2026 KB202602002 CV. Example Rp 3.500.000 15/02/2026 Lunas

📝 Cara Menggunakan

1 Login

Login sebagai super_admin atau user dengan permission sales.kontrabon.delete

2 Buka Halaman Kontra Bon

Navigasi ke: /admin/penjualan/kontrabon

3 Pilih Tab "List Kontra Bon"

Klik tab "List Kontra Bon" untuk melihat daftar kontra bon

4 Klik Tombol Hapus

Klik icon trash (🗑️) merah di kolom Aksi pada kontra bon yang ingin dihapus

5 Konfirmasi

Konfirmasi dengan klik "OK" pada dialog konfirmasi

6 Selesai

Kontra bon terhapus dan status piutang otomatis dikembalikan

⚙️ Deployment

Windows:

deploy_kontrabon_delete_feature.bat

Manual:

php artisan tinker --execute="include 'create_kontrabon_delete_permission.php';" php artisan route:clear php artisan route:cache

🔐 Permission

Permission Name: sales.kontrabon.delete
Display Name: Hapus Kontra Bon
Group: sales
Auto-assigned to: super_admin

Assign ke Role Lain:

php artisan tinker $roleName = 'admin'; // Ganti dengan nama role include 'assign_kontrabon_delete_to_role.php';

🔄 Apa yang Terjadi Saat Hapus?

  1. ✓ System cek permission user
  2. ✓ Ambil data kontra bon dengan details
  3. ✓ Loop setiap detail kontra bon:
    • Cari piutang terkait
    • Kembalikan jumlah_dibayar (dikurangi)
    • Kembalikan sisa_piutang (ditambah)
    • Update status ke 'belum_lunas'
  4. ✓ Hapus semua detail kontra bon
  5. ✓ Hapus kontra bon
  6. ✓ Commit transaction
  7. ✓ Reload tabel

⚠️ Catatan Penting

Perhatian:
  • Saat kontra bon dihapus, status piutang akan dikembalikan ke "belum lunas"
  • Jumlah dibayar pada piutang akan dikurangi sesuai pembayaran di kontra bon
  • Sisa piutang akan bertambah sesuai pembayaran di kontra bon
  • Proses ini menggunakan transaction, jika error semua akan di-rollback
