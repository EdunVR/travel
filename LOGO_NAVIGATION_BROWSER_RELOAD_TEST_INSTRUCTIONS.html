🧪 Manual Testing Instructions

Test 1: Logo Click Behavior

Steps:

  1. Open the admin dashboard with tab system
  2. Open a few tabs by clicking sidebar menu items
  3. Click the logo in the sidebar

Expected: Entire page reloads, all tabs are reset, back to dashboard

Should NOT: Load dashboard in current active tab

Test 2: Browser Refresh Keys (Ctrl+R, F5)

Steps:

  1. Open admin dashboard with multiple tabs
  2. Navigate to a specific page in active tab
  3. Press Ctrl+R or F5

Expected: Only active tab refreshes, other tabs remain unchanged

Should NOT: Reload entire page/browser

Test 3: Browser Close/Reload Warning

Steps:

  1. Open admin dashboard with multiple tabs
  2. Try to close browser tab or window
  3. Or try to navigate away by typing new URL

Expected: Browser shows warning about unsaved changes

Note: Modern browsers may not show custom message

Test 4: Hard Refresh (Ctrl+Shift+R)

Steps:

  1. Open admin dashboard with multiple tabs
  2. Press Ctrl+Shift+R

Expected: Confirmation dialog asking if you want to hard refresh

If confirmed: Full page reload, all tabs reset

Test 5: Logout Navigation

Steps:

  1. Open admin dashboard with multiple tabs
  2. Click logout button/link

Expected: Normal logout without warnings

Should NOT: Show beforeunload warning

Test 6: External Link Navigation

Steps:

  1. Open admin dashboard with multiple tabs
  2. Click any external link (if available)

Expected: Normal navigation without warnings

Should NOT: Show beforeunload warning

🔍 Debugging

Open browser console (F12) to see debug messages:

  • 🏠 Logo clicked - forcing full page reload
  • 🚫 Browser reload prevented - use tab refresh instead
  • 🔄 Browser refresh key intercepted - refreshing active tab instead
  • 🚪 Navigating away from tab system

✅ Success Criteria

  • Logo click reloads entire page (no mirroring)
  • Ctrl+R/F5 refreshes active tab only
  • Browser close shows warning
  • Hard refresh asks for confirmation
  • Logout works without warnings
  • No JavaScript errors in console
